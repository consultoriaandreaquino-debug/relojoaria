# Prompt de início (cole no Claude Code)

Leia `CLAUDE.md`, `docs/requisitos-atividade.md` e `docs/referencias-visuais.md`, e abra todas as imagens em `docs/referencias/`.

Depois desenvolva o projeto completo de ponta a ponta: e-commerce premium de relojoaria em PHP + PDO + MySQL + Bootstrap 5, pronto para o XAMPP, com identidade visual própria e todas as funcionalidades reais descritas.

Regras de execução:
- Trabalhe direto nos arquivos deste repositório. Use uma lista de tarefas para acompanhar as etapas.
- Comece pela análise dos requisitos, depois arquitetura, identidade (registre em `docs/identidade.md`) e banco; em seguida frontend, backend e integração.
- Teste cada módulo de verdade antes de avançar (banco real, servidor local, fluxos com sessão e CSRF) e faça um commit real ao fim de cada etapa testada. Não faça push.
- Não pare depois de apresentar o plano. Continue até concluir.
- Não declare nada como pronto sem verificar. Se algo não puder ser feito ou testado no ambiente, diga claramente.
- Ao final, gere `docs/auditoria.md` conforme a seção 15 do `CLAUDE.md` e me apresente o resumo.
